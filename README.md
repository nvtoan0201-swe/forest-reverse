# Focus Grove — a focus timer PWA (study build)

An offline-first, installable focus timer where you plant a tree, watch it grow while you work,
and build a little grove out of your focused sessions. This is an independent study
reimplementation of the well-known "plant a tree to stay focused" mechanic, written from scratch
in TypeScript. **It is not affiliated with, endorsed by, or connected to Seekrtech.**

All artwork and audio in this repository are original placeholder assets generated by a script —
no copyrighted game assets or strings are included.

> Bản tiếng Việt ngắn gọn ở [cuối trang](#tiếng-việt).

---

## Features

- **Core loop** — pick a duration (5–120/180 min) on the round PlantBall, choose a species and a
  tag, plant, watch the tree grow through 7 phases, then succeed or fail.
- **Timer & Stopwatch** — countdown sessions plus count-up sessions with a stoppable threshold.
- **Kill detection** — closing/navigating away mid-session withers the tree; reloading restores it.
- **System-clock guard** — moving the OS clock aborts the session instead of cheating the timer.
- **Deep focus (web simulation)** — leaving the tab is tracked and shown; 5+ minutes away kills the tree.
- **Grove, Timeline & Statistics** — daily grouped history, focus-time trend chart, forest grid,
  tag distribution, favorite species, best day/time, planting records.
- **Store** — buy species and soundscapes with coins/gems, preview audio, unlock state persisted.
- **Tags** — create/edit/soft-delete tags with 15 colors, assign to sessions.
- **Soundscapes** — 33 generated ambient loops with crossfade, SFX for clicks/growth/bell.
- **Settings** — EN/VI language, sound, notifications, 2h/3h sessions, wake lock, data
  export/import (JSON) and CSV export, clear history.
- **PWA** — installable, offline-capable, background-safe timer (Web Worker), end-of-session
  notifications.
- **Accessibility** — keyboard-operable slider, aria labels, `prefers-reduced-motion` support.

## Quick start

Requires Node.js 20+.

```bash
npm install
npm run assets   # generates placeholder tree art + audio (idempotent)
npm run dev      # http://localhost:5173
```

`npm run dev` and `npm run build` regenerate assets automatically via `predev`/`prebuild`,
so `npm run assets` is optional after the first install.

### Useful scripts

| Script | Purpose |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Type-check + production build |
| `npm run preview` | Serve the production build |
| `npm run verify` | lint + typecheck + unit tests (CI gate) |
| `npm run test` / `test:watch` | Unit tests |
| `npm run e2e` | Playwright end-to-end tests (runs a fast-mode build) |
| `npm run seed` | Regenerate catalog JSON (`src/assets/catalog`) |
| `npm run assets` | Regenerate placeholder assets (`public/assets`, gitignored) |
| `npm run assets:verify` | Check every catalog entry has assets |

### Environment flags

Copy `.env.example` to `.env` to override:

| Variable | Default | Meaning |
|---|---|---|
| `VITE_ASSET_MODE` | `placeholder` | `placeholder` = generated art/audio (safe to publish) |
| `VITE_FAST_PLANT` | `0` | `1` divides session durations by 60 for quick testing |

The app keeps four layers: `ui → application → domain ← infra`. Components never touch Dexie
directly; everything goes through repositories bound in `src/data/repositories.ts`.

## Behaviour notes (faithful reproduction)

The timer logic reproduces the documented behaviour of the original app so the focus loop feels
right:

- Coin formula: `(m < 25 ? 1 : 4) + floor(m / 5) + floor(max(m - 30, 0) / 30) * 5`.
- Tree phase: `iMax = max(600, min(t, 1800))`; below `iMax` → `floor(past * 3 / iMax)`, otherwise
  `floor(past / 1800) + 2`; clamped to `0..6`.
- Countdown yields `min(4, max(1, t / 1800))` trees; count-up always yields 4 and prunes the ones
  you didn't earn when stopping.
- Closing the tab mid-session fails the plant (`KILL_APP`); a reload restores the ongoing session.
- Free plan caps daily focus at 180 minutes (a dev "premium" toggle removes the cap).

Deviations from the original (intentional, documented here): a starting coin balance of 100 to
exercise the store, generated placeholder art/audio, and a web-only deep-focus simulation instead
of OS-level app blocking.

## Deployment

The app is a static SPA — deploy `dist/` anywhere (GitHub Pages, Netlify, Vercel, Cloudflare
Pages). Set the env vars from `.env.example` at build time. For client-side routing, configure a
fallback rewrite to `index.html`.
